# أُفُق 2030 — موقع عرض تقديمي

عرض عربي تفاعلي حول المدن الذكية ورؤية السعودية 2030، ضمن تكليف تصميم موقع للعروض التقديمية.

## التشغيل
افتح `index.html` في المتصفح. لا يتطلب تثبيت أي برامج أو تشغيل خادم.

## التحكم
- أزرار التالي والسابق أسفل الصفحة.
- الأسهم في لوحة المفاتيح، PageUp / PageDown، ومفتاح المسافة.
- زر «كل الشرائح» لعرض الفهرس.
- زر ملء الشاشة.
- التمرير بالسحب على الهاتف.

## النشر
ارفع جميع الملفات إلى مستودع GitHub عام، واربطه بـ Cloudflare Pages. إعدادات البناء: بدون أمر بناء؛ مجلد الإخراج `/`.

## ملاحظات
الرسومات الحضرية مصممة باستخدام CSS، وليست صورًا تدعي تمثيل مشروع حقيقي. المحتوى وصفي عام، وروابط المصادر الرسمية متاحة في الشريحة الأخيرة. الخط يُحمّل من Google Fonts، ويُستخدم خط احتياطي عند عدم توفر اتصال.

## النسخة السينمائية
انتقالات ثلاثية الأبعاد CSS (perspective / rotateY / depth)، وخلفيات تصويرية ذات طابع مستقبلي، وتأثيرات دخول متدرجة، مع دعم تقليل الحركة للمستخدمين الذين يفضلون ذلك. الصور العامة من Unsplash توضيحية وليست صورًا موثقة للمشروعات السعودية المذكورة. تحتاج الصور والخط إلى اتصال بالإنترنت.


## الرحلات السينمائية
في الشريحة الخامسة، اضغط على بطاقة نيوم أو الرياض أو البحر الأحمر للدخول في رحلة تصويرية مع حركة كاميرا CSS ثلاثية الأبعاد. الصور تعبيرية وليست لقطات موثقة للمشروعات نفسها. اضغط ESC للعودة.
